# 🇮🇷 イラン戦争の記憶 - インタラクティブマップ

イラン・イラク戦争（1980-1988）の現実と記憶をマップ上で知るインタラクティブなWebアプリケーションです。

## 🌟 主な機能

### 📍 マップ機能
- **インタラクティブマップ**: Leaflet.jsを使用した美しいマップ表示
- **白地図・航空写真切り替え**: 右上のボタンで地図タイプを切り替え可能
- **マーカー表示**: 各地の声の位置をマーカーで表示
- **ポップアップ**: マーカーをクリックして詳細情報を表示

### 📊 戦争の記憶機能
- **詳細情報**: 各地の戦争の記憶を詳細に表示
- **犠牲者数**: 各事件での犠牲者数を記録
- **期間情報**: 戦闘や攻撃の期間を記録

### 📝 戦争の記憶機能
- **スクロール一覧**: 右サイドバーで戦争の記憶をスクロールして閲覧
- **詳細表示**: 記憶をクリックして詳細モーダルを表示
- **検索機能**: テキスト検索で戦争の記憶を絞り込み

### 🏷️ フィルター機能
- **タグフィルター**: タグで戦争の記憶を絞り込み
- **テキスト検索**: 記憶内容、場所、作者名で検索
- **リアルタイム更新**: フィルター適用時にマップとリストが即座に更新

### 🔥 ヒートマップ機能
- **ヒートマップ表示**: 戦争の記憶が多く集まっている場所を視覚的に表示
- **切り替え可能**: 右上のボタンでヒートマップの表示/非表示を切り替え
- **フィルター連動**: フィルター適用時にヒートマップも更新

## 🚀 使用方法

### 1. アプリケーションの起動
```bash
# ローカルサーバーを起動（例：Python）
python -m http.server 8000

# または Node.js の http-server
npx http-server

# ブラウザでアクセス
http://localhost:8000
```

### 2. 基本的な操作
- **マップ操作**: ドラッグで移動、スクロールでズーム
- **マーカークリック**: ポップアップで詳細表示
- **詳細表示**: 📖ボタンまたは戦争の記憶をクリック

### 3. フィルターの使用
- **タグ選択**: ドロップダウンからタグを選択（化学兵器、空爆、民間人犠牲など）
- **テキスト検索**: 検索ボックスにキーワードを入力
- **リアルタイム更新**: 入力と同時に結果が更新されます

### 4. 地図の切り替え
- **航空写真**: 右上の「航空写真」ボタンをクリック
- **白地図**: 右上の「白地図」ボタンをクリック
- **ヒートマップ**: 右上の「ヒートマップ表示」ボタンをクリック

## 📊 データ構造

```javascript
{
    id: 1,
    location: "ホラムシャフル",
    coordinates: [30.4394, 48.1664], // [緯度, 経度]
    text: "戦争の記憶の内容",
    tags: ["都市戦", "占領", "破壊", "市民犠牲"],
    date: "1980-09-22",
    author: "証言者名",
    casualties: "約7000人死亡",
    duration: "34日間"
}
```

## 🎯 カスタマイズ

### 新しい戦争の記憶を追加
`script.js`の`iranVoices`配列に新しいデータを追加：

```javascript
{
    id: 9,
    location: "新しい場所",
    coordinates: [緯度, 経度],
    text: "新しい戦争の記憶",
    tags: ["新しいタグ"],
    date: "198X-XX-XX",
    author: "新しい証言者",
    casualties: "犠牲者数",
    duration: "期間"
}
```

### スタイルの変更
`styles.css`を編集してデザインをカスタマイズできます。

### 機能の拡張
`script.js`に新しい機能を追加できます。

## 🔧 トラブルシューティング

### データが表示されない場合
- ブラウザのJavaScriptが有効になっているか確認
- ネットワーク接続を確認
- ブラウザのキャッシュをクリア

### マップが表示されない場合
- インターネット接続を確認
- ブラウザのコンソールでエラーを確認

### フィルターが動作しない場合
- JavaScriptが有効になっているか確認
- ブラウザのキャッシュをクリア
